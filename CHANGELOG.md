- added (owner decision, the `hover` prototype): nested data in tables. With the data pane's cursor on a cell holding an object or an array, a sub-table of its data opens under the row (an object as keys over values, an array of objects as a table, scalars joined with ` · `, other arrays a line per item), each level indented with its own column widths; `j`/`k` walk into its lines and out the bottom (`rows.move` walks the drawn lines, counts included), `h`/`l`/`0`/`^`/`$` move along one (new verb `rows.column`, bound ahead of the list's column verb while the cursor is in a sub-table), a nested cell there opens the next level, and `y` / `enter` copy and open the value under the cursor. New settings `table.nested` (`hover` default, `summary`: the summary view as before) and `table.nested-rows` (`8`).
- added: setting `rebuild.value-edit` (`current` default, `queue`, `previous`): what a value edit made while a large document's restructure is rebuilt off the loop acts on. `current` is the behaviour below (the rebuild settled on the loop, the row at the cursor in the current document); `queue` does not wait: the edit is recorded against the shown row's path and applied when the rebuild lands, the path resolved in the new document (gone: reported, kept as an orphaned patch); `previous` acts at once on the shown result's row, a patch by path the next rebuild resolves (orphaned if gone).
- added: setting `paste.text-on-tree` (`keys` default, `values`, `ignore`): what text that is not JSON pasted on the edited tree does under `paste.on-tree json`. `keys` is the behaviour below; `values` adds each line as a string value (value patches: items appended to an array, or an array of them under a new placeholder key in an object), one undo step, refused under `[]`; `ignore` pastes nothing with a plain notice.
